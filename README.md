# 防災訓練シミュレーター(Disaster Drill Simulator)

災害が起きた場面に置かれ、限られた時間と情報のなかで行動を選び、
その結果を見て、なぜそうなったのかを知り、もう一度挑戦するための Web アプリ。

**防災知識を読むアプリではなく、防災判断を体験するアプリ**である。
正解を選ぶクイズにはせず、「揺れている間は身を守る → 収まったら周囲を確認 → 避難判断」という
状況依存の判断を要求し、選んだ行動がその後の展開そのものを変える。

## 訓練モード

- **初心者** — 時間制限なし。行動ごとに解説を表示
- **標準** — 時間制限あり。解説は結果画面でまとめて表示
- **挑戦** — 時間制限あり。シード付きの乱数で場面に出来事が加わる

## 目玉と、それをどう守っているか

このアプリの主張は「**判断が次の状況を変える**」である。主張は文章ではなくデータ検査で守る。

- **到達可能性・参照整合・非循環・終端保証**(T-030〜T-033)—— 開始場面からすべての場面へ
  到達でき、参照先が実在し、閉路がなく、どの経路も有限手で終わる
- **判断が効く**(T-035)—— どの場面でも、行動どうしで安全度への効き方が同一でない。
  全部同じなら、それは選択肢ではなく飾りである
- **分岐が実在する**(T-036)—— 各シナリオに、遷移先の異なる行動の組が最低ひとつある。
  分岐 0 のシナリオは出荷しない

いずれも件数の定数ではなく**不変量**で書いてあるので、シナリオを足しても検査は生き続ける。

## 検査

```
npm run verify          # typecheck + lint + test + 本文検査 + build + 出荷物検査
npm run verify:fast     # build と出荷物検査を飛ばす
npm test                # 単体 + 画面 + 文書の検算
python scripts/prose_check.py   # 日本語本文の字種・制御文字・英単語混入
```

`scripts/prose_check.py` は二つのことをする。共通の `harness/text_hygiene.py` は
既定で `data` を飛ばすので、**本文のあるファイルを明示して渡し直す**。あわせて、
**日本語の文中に単独で現れた ASCII 語**を出す。字種検査は別字種と制御文字しか見ないので、
`water` のような正当な文字で書かれた誤りを通してしまう(開発中に実際に踏んだ)。

## 技術構成

```
Next.js 15 / React 19 / TypeScript / SVG / CSS
```

バックエンド・データベース・外部 API・認証・環境変数を**一つも使わない**。
`output: "export"` の静的エクスポートで、`out/` の静的ファイルだけで動作する。
記録は端末のブラウザ内(localStorage)にのみ保存し、個人情報は収集しない。

## 素材

外部の画像・図・音源を一つも使っていない。画面に出る図はすべて
このリポジトリ内の SVG(`src/components/DisasterScene.tsx`)と CSS で描いている。

シナリオの内容は、消防庁・気象庁などが公開している一般的な防災の考え方
(警戒レベル、津波避難の原則、土砂災害の前兆、通電火災の防止など)を踏まえた創作であり、
特定の資料の文章を転載したものではない。

## 安全上の注意

本アプリは防災教育・訓練・シミュレーションを目的とする。実際の災害時は、
自治体・消防・警察・気象機関などの最新情報および現地の指示を優先すること。
シナリオ中の選択肢は、すべての災害・建物・地域に当てはまる避難手順ではない。
